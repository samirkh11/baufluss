# Fonts

Liberation Sans (Regular, Bold, Italic) by Red Hat, licensed under the SIL Open Font License 1.1
(https://github.com/liberationfonts/liberation-fonts). Metric-compatible with Helvetica/Arial.

The PDFs embed these fonts instead of the PDF standard fonts: PDF/A-3 (ZUGFeRD / Factur-X e-invoices)
requires every font to be embedded.
