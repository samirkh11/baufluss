# GAEB-Testdateien

**Selbst erzeugte** Beispiele (keine Originale aus Fremdsoftware) zum Ausprobieren und für die
automatischen Tests des GAEB-Imports/-Exports:

| Datei | Inhalt |
| --- | --- |
| `lv-dachsanierung.x83` | GAEB DA XML 3.3, Phase X83: verschachtelte Titel (01, 02 → 02.01, 02.02), Pauschal-, Bedarfs-, Alternativ- und Textposition, mehrere Absätze, XML-Entities |
| `lv-einfach-3.2.x81` | GAEB DA XML 3.2, Phase X81: flache Positionsliste ohne Titel, Langtext ohne Kurztext |

Import: Projekt → Reiter *Angebote* → **GAEB-Import**. Der Export eines Angebots erzeugt eine
Datei im Format X84 (Angebotsabgabe).

Hinweis: Die Dateien folgen der GAEB-DA-XML-Struktur nach bestem Wissen, wurden aber nicht gegen
das offizielle GAEB-Schema geprüft. Echte Dateien aus Ausschreibungsportalen bitte gegentesten.
